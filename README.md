# githubhomepage
A GitHub Pages homepage built with Jekyll.

## Deploy

If you want the site at `https://USERNAME.github.io/`, create a repo named
`USERNAME.github.io` and point this folder to it:

```
git remote set-url origin https://github.com/jeppejohansen/jeppejohansen.github.io.git
```

Then push:

```
git push -u origin main
```

Enable GitHub Pages in the repo settings (Pages → Deploy from branch → `main`
/ root). The site updates on every push.
